NUMBERS CARD BINDER
1. Descomprime el ZIP.
2. Sube TODOS los archivos y carpetas a la raíz de tu repositorio GitHub Pages.
3. Activa GitHub Pages desde Settings > Pages > Deploy from a branch > main / root.
4. Abre la URL HTTPS en Chrome Android > menú ⋮ > Instalar aplicación o Añadir a pantalla principal.
5. El progreso se guarda en el navegador. Usa Exportar respaldo para conservarlo.
